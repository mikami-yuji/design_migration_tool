# デザイン依頼書データフォルダ移行ツール

システムから生成されたPDFファイルを検知し、ポップアップで確認後に指定フォルダへ自動コピー（元のファイルは残す）するWindowsデスクトップツールです。

## 機能

- 📁 **フォルダ監視**: 指定フォルダを常時監視し、新しいPDFファイルを自動検知
- 💬 **ポップアップ確認**: PDFが検知されると「このデータを指定のフォルダに移しますか？」とポップアップ表示
- 📂 **自動コピー**: 確認後、元のファイルを残したまま、指定フォルダにPDFを自動コピー（同名ファイルのリネーム処理付き）
- ⚙️ **初期設定GUI**: 初回起動時にフォルダ選択ダイアログで監視元・移動先を設定
- 🔧 **システムトレイ常駐**: バックグラウンドで動作し、トレイから操作可能
- 🔄 **二重防止＆やり直し検知**: `history.json` を使ってファイルのサイズと最終更新日時(mtime)を自動記録。同じファイルの二重ポップアップを防ぎつつ、データのやり直し再出力（上書き）は確実に検知して再ポップアップします。


## 📦 他の社員への配布方法（セキュリティソフト/EXE誤検知対策）

一般的なPyInstallerによるEXE化処理は、ファイル圧縮技術（UPX）を使用するため、セキュリティソフトに「不審なファイル」と誤認識されやすくなります。

このプロジェクトでは、UPX圧縮を完全に無効化し、余計なライブラリを一切含めないクリーンな環境で単一のEXEを自動ビルドするスクリプト **`build_exe.bat`** を用意しています。これにより、**セキュリティソフトによる誤検知を極限まで低減した安全なEXEファイル**を作成できます。

### 1. 配布用EXEの作成方法（開発者向け）

他の社員に配布するためのEXEファイルは、以下の手順で作成します。

1. プロジェクトフォルダ直下にある **`build_exe.bat`** をダブルクリックします。
2. コマンドプロンプトが自動で立ち上がり、一時的なクリーン仮想環境の作成、本番に必要な最小限の依存パッケージインストール、およびUPXなしでの安全な PyInstaller ビルドが行われます。
3. ビルドが完了すると、フォルダ内に **`dist/design_migration_tool.exe`** が生成されます。

### 2. 一般社員への配布と利用手順

生成された **`design_migration_tool.exe`** を他の社員へ配布し、以下の手順を案内してください。

1. 配布された **`design_migration_tool.exe`** を、PC上の任意の場所（デスクトップやマイドキュメントなど）に配置します。
2. 配置したEXEファイルをダブルクリックして起動します。
3. 黒い画面（コマンドプロンプト）を表示させることなく、バックグラウンドでツールが起動し、タスクバーの右端（システムトレイ）に常駐します。
4. 初回起動時は自動的に設定画面が立ち上がりますので、監視フォルダと移動先フォルダの指定を行ってください。

> [!NOTE]
> もしダウンロード時や初回実行時にWindows SmartScreenによって「WindowsによってPCが保護されました」と青い画面の警告が表示された場合は、**「詳細情報」**をクリックした後に**「実行」**ボタンを押すよう案内してください。これは無署名の自作ツールで初回実行時に必ず発生するWindowsの標準的な挙動であり、安全上問題ありません。

## 必要条件

- Python 3.10以上
- Windows 10/11

## セットアップ手順

### 1. リポジトリのクローン

```bash
git clone <リポジトリURL>
cd デザイン依頼書データファルダ移行ツール
```

### 2. 仮想環境の作成（推奨）

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 4. アプリケーションの起動

#### 簡単起動（推奨）
フォルダー内にある **`起動する.bat`** をダブルクリックするだけで、コマンドプロンプトの黒い画面を表示させずにバックグラウンドで起動できます。

#### コマンドラインからの起動
```bash
py main.py
```

初回起動時は、設定ダイアログが表示されます。


## 設定

### 初回起動時

アプリケーションを初めて起動すると、GUIダイアログが表示されます。

1. **監視フォルダ**: PDFが生成されるフォルダを「参照...」ボタンで選択
2. **移動先フォルダ**: PDFの保存先フォルダを「参照...」ボタンで選択
3. 「**保存して開始**」をクリック

### config.json で直接編集

`config.json` を直接編集することもできます。

```json
{
  "watch_folder": "C:\\Users\\ユーザー名\\Documents\\PDFの生成元",
  "destination_folder": "C:\\Users\\ユーザー名\\Documents\\デザイン依頼書",
  "file_extensions": [".pdf"],
  "check_interval": 1.0,
  "show_notification_on_move": true
}
```

| 項目 | 説明 | デフォルト値 |
|------|------|-------------|
| `watch_folder` | PDF生成を監視するフォルダパス | （初回設定で指定） |
| `destination_folder` | PDF移動先フォルダパス | （初回設定で指定） |
| `file_extensions` | 監視対象のファイル拡張子 | `[".pdf"]` |
| `check_interval` | 監視間隔（秒） | `1.0` |
| `show_notification_on_move` | 移動完了通知の表示 | `true` |

### 設定変更

システムトレイアイコンを右クリック → 「⚙ 設定変更」で再設定可能です。

## システムトレイ操作

アプリケーションはシステムトレイに常駐します。トレイアイコンを右クリックすると以下の操作が可能です：

| メニュー | 機能 |
|----------|------|
| ▶ 監視を開始 / ⏸ 監視を停止 | フォルダ監視の切り替え |
| ⚙ 設定変更 | フォルダ設定ダイアログを開く |
| ✕ 終了 | アプリケーションを終了 |
